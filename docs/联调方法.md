# 联调方法（鸿蒙客户端 × backend 服务端）

本轮 Phase 3 验证的标准联调流程：**一台 HarmonyOS 模拟器上的 App + 一个 Node 探针**
（`tools/play-probe.mjs`）充当第二玩家。非双鸿蒙客户端。

## 1. 启动服务器

```powershell
cd backend
$env:HOST='0.0.0.0'; $env:PORT='3001'
pnpm start        # 或 pnpm dev（tsx watch）
```

`HOST=0.0.0.0` 是必须的：模拟器内 App 通过宿主机局域网 IP 访问服务器，
默认 `127.0.0.1` 只监听本机回环会导致连接失败。

## 2. 配置 App 服务器地址

`entry/src/main/ets/entryability/EntryAbility.ets` 中硬编码
`http://<宿主机局域网IP>:3001`（当前为 `http://192.168.2.66:3001`，
即本机验证时的 LAN IP）。IP 变化时修改后重新 `devecocli build` 安装。

## 3. 启动模拟器并安装 App

```powershell
devecocli emulator start "Mate 90 Pro"
devecocli run
```

## 4. 第二玩家探针

探针必须从 `backend/apps/server` 目录运行（依赖其中的 `ws` 包）：

```powershell
cd backend/apps/server
node ../../../tools/play-probe.mjs <roomCode>     # 自动对局探针
node ../../../tools/kick-host.mjs                 # 房主踢人探针（先建房间）
```

- `play-probe.mjs`：join + ready，轮到自己自动出牌（mustChallenge/手牌空时
  自动质疑），每 10s 主动 @ping，30min 超时，打印全部对局事件。
- 房间码获取：App 端创建房间后 UI 显示；或从探针/服务器日志中取
  （PowerShell 提取须 `-cmatch '^[A-Z0-9]{6}$'`，`-match` 不区分大小写会误匹配）。
- 环境变量：`WS_URL`（默认 `ws://127.0.0.1:3001/ws`）、`PROBE_NICKNAME`。

## 5. App 端 UI 驱动（点击）

```powershell
cd tools
.\click-text.ps1 -Text "加入房间"
```

脚本每次点击前重新 dumpLayout 再按文本定位（模拟器重启后 UI 坐标会偏移，
不能复用旧坐标）。可用环境变量覆盖 `HDC_PATH`/`HDC_TARGET`/`DUMP_DIR`。

首页关键输入框位置（dumpLayout 中的大致 y 坐标，仅供排障参考，以实际 dump 为准）：
昵称（创建区）≈1064、昵称（加入区）≈1639、房间码 ≈1849、加入房间按钮 ≈2059。
两个昵称字段联动，昵称为空时创建/加入按钮禁用。

## 6. 日志观察

```powershell
hdc -t 127.0.0.1:5555 shell hilog | Select-String "A0ff00|A00000"
```

- `A0ff00`：页面导航日志（`push game page, status=`、`back to lobby` 等）
- `A00000`：SocketManager 日志（`session resumed: room=`、`session resume failed:` 等）

服务器端：pino JSON 日志（stdout），关键事件 `room_created/room_joined/
player_disconnected/player_reconnected/challenge_called`。

## 常用验收操作

| 场景 | 操作 |
|------|------|
| 正常对局 | App 建房 → 探针加入 → 双方 ready → 自动开局 |
| 质疑 | 轮到对方出牌后 App 点"质疑"，或探针自动质疑 |
| 对局结束/再来一局 | 打到淘汰，结算面板 → "再来一局" / "返回大厅" |
| 断线恢复 | 对局中 `hdc shell aa force-stop <bundle>` 后重启 App，应自动恢复进对局 |
| 被踢 | `kick-host.mjs` 建房，App 加入，探针 2.5s 后自动踢出 |

## HDC 排障约定

只针对 HDC 本身处理，不要按进程名批量杀：`hdc kill` + `hdc start -r` 重启、
`hdc list targets` 查询；仍无效则 `devecocli emulator start "Mate 90 Pro"` 重启模拟器。
