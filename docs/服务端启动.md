# 服务端启动说明（backend/）

`backend/` 是从上游 monorepo（`Xin-zimu/bluff-tavern`，网页版仓库，仅作上游参考）
提取的**双传输游戏服务端**：原生 WebSocket（`/ws`，鸿蒙客户端使用）+ Socket.IO
（网页客户端使用），共享 `packages/shared` 协议与游戏逻辑。

上游 monorepo 中的 `apps/web`、部署脚本、素材等未纳入本仓库。

## 目录结构

```
backend/
├── apps/server/          # Fastify + ws + Socket.IO 服务端
│   ├── src/
│   │   ├── config/       # 环境变量读取（env.ts）
│   │   ├── game/         # 对局引擎（回合/质疑/惩罚/淘汰）
│   │   ├── realtime/     # 推播调度
│   │   ├── rooms/        # 房间管理
│   │   ├── socket/       # Socket.IO 传输
│   │   ├── ws/           # 原生 WebSocket 传输（/ws 信封协议）
│   │   └── main.ts       # 入口
│   ├── tests/            # 6 个测试文件（含 ws-transport.test.ts）
│   └── scripts/          # live-*.ts 冒烟脚本
├── packages/shared/      # 协议类型与共享逻辑（workspace:*）
├── package.json          # workspace 根（server-only 脚本）
├── pnpm-workspace.yaml
├── pnpm-lock.yaml        # 与 server+shared 匹配的锁文件
├── tsconfig.base.json
└── vitest.config.ts
```

## 安装依赖

需 pnpm ≥ 11：

```powershell
cd backend
pnpm install
```

## 运行测试

```powershell
pnpm test        # 91/91（服务端 + shared；上游全仓为 125，差额为未纳入的 web 测试）
```

## 构建与启动

```powershell
pnpm build       # 构建 shared + server -> dist/
pnpm start       # node apps/server/dist/main.js
# 开发模式（tsx watch）：
pnpm dev
```

## 配置（环境变量）

服务器**不自动加载 .env**，直接读取进程环境变量（`src/config/env.ts`）；
`backend/.env.example` 列出了全部支持的变量：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `HOST` | `127.0.0.1` | 监听地址。**供模拟器/真机联调时必须设为 `0.0.0.0`**，否则客户端无法从设备访问宿主机 |
| `PORT` | `3001` | 监听端口 |
| `CLIENT_ORIGIN` | `http://localhost:5173` | Socket.IO CORS 来源 |
| `LOG_LEVEL` | `info` | pino 日志级别 |

PowerShell 示例：

```powershell
$env:HOST='0.0.0.0'; $env:PORT='3001'
pnpm start
```

## 关键行为（与客户端联调相关）

- `/ws` 信封协议：请求 `{v:1,id,event,payload}`，ack `{v:1,id,ok,data|error}`，
  推送 `{v:1,event,payload}`，心跳 `@ping`/`@pong`（无 id）。
- **心跳为客户端主动**：服务器从不主动发 `@ping`；客户端每 10s 发 `@ping`、
  服务器回 `@pong`。空闲约 45s 断开。
- 断线后有宽限期；超时移除玩家并使其 sessionToken 失效（重连时报 SESSION_NOT_FOUND）。
- 回合 15s 超时服务器自动代打（autoAct）；手牌打空触发强制质疑链（mustChallenge）。
